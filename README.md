# Sistema MVP - Ótica Jurado

Repositório oficial para o desenvolvimento do MVP de automação de registos da Ótica Jurado, substituindo os fichários manuais por uma aplicação desktop segura e eficiente.

##  Tecnologias Utilizadas
* **Linguagem:** Python 3.12
* **Interface Gráfica:** Tkinter
* **Banco de Dados:** MySQL (PyMySQL)
* **Segurança:** Hashing de senhas e consultas parametrizadas (Prepared Statements) contra SQL Injection.

##  Estrutura do Projeto
- `/src` - Código-fonte da aplicação (camadas de visão, controle e dados).
- `/tests` - Testes automatizados unitários e de integração.
- `/docs` - Documentação de requisitos, arquitetura e protótipos.
